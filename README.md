# 動揺データPDF → Excel ツール

2種類あります。

| ツール | 用途 |
|---|---|
| **単月ツール** (`excel-tool/`) | 1回分のPDFを表にして、基準値超過・目標値超過を抽出 |
| **年度推移管理ツール** (`trend-tool/`) | 4月〜翌3月の毎月の検査を蓄積し、**箇所ごとの推移**を追跡 |

どちらもすぐ使える状態です。開発メモは [HANDOFF.md](HANDOFF.md) を参照してください。

---

# 単月ツール

軌道検測(動揺測定)の結果PDFから、キロ程ごとの「上下動」「左右動」を読み取り、
Excelの表として整理するツールです。

## できること

| シート | 内容 |
|---|---|
| **設定** | 目標値・基準値・黄色強調値を職場ごとに変更できます |
| **全データ** | PDFの全行(NO・列車速度・時刻・キロ程・上下動・左右動・超過印・備考) |
| **①基準値超過** | 上下動もしくは左右動が **基準値(初期値0.25)以上** の行 |
| **②目標値超過** | **目標値(初期値0.20)以上〜基準値未満** の行。<br>**黄色強調値(初期値0.24)以上** のセルは黄色で強調 |
| **PDF貼付** | 取込ボタンと、PDFを貼り付けて取り込むためのシート(下記④) |

- 「0.25以上を目標値/0.30以上を基準値」の職場では、**設定シートの数値を
  0.25 / 0.30 / 0.29 に変えるだけ**で①②の抽出と黄色強調が切り替わります。
  黄色・赤色の強調(条件付き書式)も設定シートを参照しているため自動で追従します。

## ④「PDFを貼り付けるシート」はできるのか?

**Excelの標準機能だけでは不可能ですが、マクロ(VBA)を使えば近いことが実現できます。**
本ツールでは次の2通りを用意しています。

1. **PDFファイルを選択して取込(推奨)**
   ボタンを押してPDFを選ぶだけです(複数選択可)。確実に動く方式です。
2. **貼り付けたPDFを取り込む(=④の方式)**
   「PDF貼付」シートにPDFをコピー&貼り付け(またはドラッグして埋め込み)し、
   ブックを保存してからボタンを押すと、ブック内に埋め込まれたPDFを取り出して
   読み取ります。
   ※ Excelは貼り付けたPDFを「アイコン(オブジェクト)」としてブック内部に保存する
   だけで中身を読む機能がないため、マクロでブック内部からPDFを取り出しています。
   OneDrive上に保存したブックでは使えないなどの制約があります。

PDFの読み取り自体は、**Power Query(Excel 2021 / Microsoft 365)** を第一候補、
**Word変換(Word 2013以降)** を第二候補として自動で試します。
どちらも使えない古い環境では読み取りできません(その場合は後述のPythonスクリプトを利用)。

## ファイル構成

```
excel-tool/
  動揺データ抽出ツール_テンプレート.xlsx … ツール本体(マクロ組込み前)
  vba/
    modMain.bas      … ボタン・取込・再抽出などのメイン処理
    modEngine.bas    … PDF解析(Power Query方式 / Word変換方式)
    modEmbedded.bas  … 貼り付けたPDFの取り出し(④)
sample/
  サンプル出力_大月保技セ_20260604.xlsx … 添付PDF(2026/06/04測定)を変換した実例
scripts/
  pdf_to_excel.py    … Python版の変換スクリプト(パソコンにPythonがある場合)
  build_template.py  … テンプレートを再生成するスクリプト(開発用)
```

## 初回セットアップ(1回だけ)

1. `excel-tool/動揺データ抽出ツール_テンプレート.xlsx` をExcelで開く
2. `Alt + F11` でVBAエディタを開き、メニューの
   **ファイル → ファイルのインポート** で `excel-tool/vba` の
   `modMain.bas`・`modEngine.bas`・`modEmbedded.bas` を3つともインポート
3. VBAエディタを閉じ、**F12(名前を付けて保存)** で
   ファイルの種類を **「Excel マクロ有効ブック (*.xlsm)」** にして保存
4. `Alt + F8` → **初期設定** を実行(PDF貼付シートにボタンが設置されます)

あとは出来上がった .xlsm を職場内で共有すれば、各自がそのまま使えます。
(開いたときに「マクロを有効にする」の許可が必要です)

> **手順3〜4が最も重要です。** `.xlsx` のまま保存するとインポートしたマクロは
> 消えてしまいます。必ずファイルの種類を **「Excel マクロ有効ブック (*.xlsm)」**
> に変えて保存してください。

### 困ったとき

| 症状 | 原因と対処 |
|---|---|
| **Alt+F8 のマクロ一覧が空っぽ** | 手順2のインポートがまだです。配布ファイルは `.xlsx` でマクロを1つも持っていないため一覧は空になります。先に Alt+F11 から3つの `.bas` をインポートしてください |
| 一覧に「初期設定」が出てこない | インポートしたモジュールが別のブックに入っている可能性があります。VBA画面左の一覧で、このブックの名前の下に `modMain` があるか確認してください |
| ボタンを押しても何も起きない | `.xlsx` で保存し直したためマクロが失われています。もう一度インポートし、`.xlsm` で保存してください |
| ファイルを開くと黄色い警告バーが出る | 「コンテンツの有効化」を押してください。押さないとマクロは動きません |
| 「PDFファイルを選択して取込」でエラー | お使いのExcelがPDF読み取りに対応していない可能性があります(Power Query / Word が必要)。下記のPython版をご利用ください |

## 使い方

1. 「PDF貼付」シートの **「PDFファイルを選択して取込」** を押してPDFを選ぶ
   (または、シートにPDFを貼り付けて保存 → **「貼り付けたPDFを取り込む」**)
2. 「全データ」「①基準値超過」「②目標値超過」が自動で埋まります
3. 設定シートの値を変えたときは **「設定変更後の再抽出」** を押す
   (PDFを読み直さずに①②を作り直します)

複数のPDFをまとめて取り込むと、測定日・元ファイル名の列で区別できます。

## Python版(参考)

Pythonが使えるパソコンでは、マクロなしで確実に変換できます:

```bash
pip install pdfplumber openpyxl
python scripts/pdf_to_excel.py 配布された.pdf -o 抽出結果.xlsx
# しきい値を変える場合
python scripts/pdf_to_excel.py 配布された.pdf -o 抽出結果.xlsx --target 0.25 --limit 0.30 --yellow 0.29
```

`sample/` の実例はこのスクリプトで生成したものです
(添付PDFの全509行、①9件はPDFの`*`印と完全一致、②99件)。

## 注意事項

- VBA版(Power Query方式・Word変換方式)は、お使いのExcel環境での動作確認を
  お願いします。様式が異なるPDFでは読み取りできない場合があります。
- `vba/*.bas` は日本語版ExcelのVBAエディタで正しくインポートできるよう
  **Shift-JIS** で保存しています(GitHub上では文字化けして見えますが正常です)。
- PDFがスキャン画像(文字情報なし)の場合は読み取りできません。

# 年度推移管理ツール

4月〜翌年3月を1年度として毎月の検査を蓄積し、**同じ箇所の推移**を追えるブックです。

## シート構成

| シート | 内容 |
|---|---|
| 設定 | 目標値/基準値/黄色強調値 に加え、**同一箇所とみなす距離(m)** と年度 |
| PDF貼付 | 取込ボタン(VBA) |
| **推移表** | 箇所ごとの4月〜3月の推移。年間最大・前年度値・施工日・施工内容つき |
| **グラフ** | 箇所選択式の折れ線(目標値・基準値の水平線入り)+ ワースト5 |
| 全データ | 取り込んだ全行(月列つき) |
| ①基準値超過 / ②目標値超過 | 全月分の抽出一覧 |
| 箇所メモ | 手入力メモの保管場所(推移表の「メモ」列と連動) |
| 施工記録 | 線別・キロ程・施工日・内容を手入力 |
| 取込履歴 | 月別の取込状況 |
| 前年度実績 | 新年度開始時に前年度の推移表を退避 |

## 「同じ箇所」の判定

キロ程は毎月わずかにずれる(例: 4月 104.880 → 5月 104.891)ため、
**設定した距離以内で連続する検出点を1つの箇所**として扱います(初期値±20m)。

- 判定は**線別ごと・上下動と左右動は別々**に行います
- グループ分けは保存せず**毎回すべて計算し直す**方式です。
  距離を20m→70mに変えて再計算すると、**4月以降の過去の月も含めて組み替わり**、
  それまで別々だった箇所が1つにまとまります(逆に戻すこともできます)
- 代表キロ程は「その箇所で最大値が出たときのキロ程」で、月をまたいでも固定です
- 箇所Noは再計算のたびにキロ程順で振り直されます。
  PDFのNOとは無関係なので、**恒久的な管理はキロ程で行ってください**
- 施工記録を推移表に直接書かず別シートに持つのは、組み替えで行がズレないためです

## 手入力した備考は消えないか

**消えません。** 備考は2列に分かれています。

| 列 | 誰が書くか | 再計算したら |
|---|---|---|
| **備考(PDF自動)** | PDFに元から入っている「巌Ｔ」等 | 毎回PDFから書き直されます |
| **メモ(手入力)** | あなた | **残ります**(うすい橙色の入力欄) |

PDFに備考がない箇所へ後から書き足したい場合は、推移表の **「メモ」列に直接入力**してください。
入力内容は再計算の直前に「箇所メモ」シートへ**線別+キロ程で自動保存**され、
グループ化し直したあとに同じ位置の箇所へ貼り直されます。
箇所Noが変わっても、距離設定を変えて箇所が組み替わっても、位置で追いかけるので迷子になりません。

- 距離を広げて2つの箇所が1つに併合された場合、両方のメモが「 / 」でつながれます(どちらも失われません)
- 同じ位置の上下動と左右動の両方に表示されます(トンネル名や踏切など位置の情報のため)
- 「箇所メモ」シートに直接書いても構いません

## 「−」の意味

お使いのPDFは**0.15G以上の箇所のみ掲載される**様式のようです。
そのため、取込済みの月にその箇所の記載がない場合は空欄ではなく **「−」** と表示し、
「0.15G未満に収まっていた」ことが読み取れるようにしています。

## Python版での使い方(VBAなしで今すぐ使えます)

```bash
# 複数月をまとめて取り込む(数字は暦月)
python scripts/build_trend_workbook.py -o 2026年度.xlsx \
  --pdf 4:4月.pdf --pdf 5:5月.pdf --pdf 6:6月.pdf

# 同一箇所の距離を±70mに変えて作り直す(過去分も再グループ化されます)
python scripts/build_trend_workbook.py -o 2026年度.xlsx \
  --pdf 4:4月.pdf --pdf 5:5月.pdf --pdf 6:6月.pdf --tol 70

# 空のテンプレートだけ作る
python scripts/build_trend_workbook.py -o テンプレート.xlsx

# 翌月分を足すとき: 手入力(メモ・施工記録)を前のファイルから引き継ぐ
python scripts/build_trend_workbook.py -o 2026年度.xlsx --carry 先月まで.xlsx \
  --pdf 4:4月.pdf --pdf 5:5月.pdf --pdf 6:6月.pdf --pdf 7:7月.pdf
```

> `--carry` を付けると、既存ブックの「箇所メモ」と、推移表に直接入力されたメモ、
> 「施工記録」を読み取って引き継ぎます。

## 使うファイル

| ファイル | 中身 |
|---|---|
| **`trend-tool/動揺データ推移管理_2026年度_大月保技セ下線.xlsx`** | **実際に配布されたPDF(2026/06/04)を取り込み済み**。これを使い始めてください |
| `trend-tool/動揺データ推移管理ツール_テンプレート.xlsx` | 空のテンプレート(他の線別を作るとき用) |
| `trend-tool/vba/` | インポートする3つのマクロ |

### 初回セットアップ

1. 使いたい方の .xlsx をExcelで開く
2. `Alt + F11` →「ファイル」→「ファイルのインポート」で
   **`modTrend.bas` / `modEngine.bas` / `modEmbedded.bas`** の3つをインポート
   (単月ツールの `modMain.bas` は**入れないでください**。マクロ名が重複します)
3. `Alt + F11` で戻り、**F12** →「Excel マクロ有効ブック (*.xlsm)」で保存
4. `Alt + F8` →「初期設定」を実行 → ボタンが4つ設置されます

### 毎月の作業

1. 「PDFファイルを選択して取込」でその月のPDFを選ぶ(貼り付け取込も可)
2. 推移表・グラフ・①②が自動更新されます
3. 同じ月を取り直すと、その月の分だけ入れ替わります(二重計上しません)

ボタンは4つです ―「PDFファイルを選択して取込」「貼り付けたPDFを取り込む」
「再計算」(設定やメモを変えたとき)「新年度開始」(年度末に)。

### 他の線別のファイルを作るには

テンプレートをコピーしてファイル名を変え、その線別のPDFを取り込んでください。
上線・下線を1つのファイルに混ぜても線別ごとに分けて集計されますが、
ファイルを分けたほうが見やすいと思います。

## デモ(見え方の確認用)

`sample/デモ_推移管理_2026年度.xlsx` は、実PDF(6月)と疑似データ(4・5・7月)で
推移の見え方を確認できるようにしたものです。

**箇所No147(下線 105.385付近・上下動)** が、
4月 0.20 → 5月 0.22 → **6月 0.26(基準値超過)** → 6/15むら直し施工 → **7月 0.16** と
推移する例になっています。グラフシートでも確認できます。
