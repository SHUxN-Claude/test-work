# 動揺データPDF → Excel 抽出ツール

軌道検測(動揺測定)の結果PDFから、キロ程ごとの「上下動」「左右動」を読み取り、
Excelの表として整理するツールです。

## できること

| シート | 内容 |
|---|---|
| **設定** | 目標値・基準値・黄色強調値を職場ごとに変更できます |
| **全データ** | PDFの全行(NO・列車速度・時刻・キロ程・上下動・左右動・超過印・備考) |
| **①基準値超過** | 上下動もしくは左右動が **基準値(初期値0.25)以上** の行 |
| **②目標値超過** | **目標値(初期値0.20)以上〜基準値未満** の行。<br>**黄色強調値(初期値0.24)以上** のセルは黄色で強調 |
| **PDF貼付** | 取込ボタンと、PDFを貼り付けて取り込むためのシート(下記④) |

- 「0.25以上を目標値/0.30以上を基準値」の職場では、**設定シートの数値を
  0.25 / 0.30 / 0.29 に変えるだけ**で①②の抽出と黄色強調が切り替わります。
  黄色・赤色の強調(条件付き書式)も設定シートを参照しているため自動で追従します。

## ④「PDFを貼り付けるシート」はできるのか?

**Excelの標準機能だけでは不可能ですが、マクロ(VBA)を使えば近いことが実現できます。**
本ツールでは次の2通りを用意しています。

1. **PDFファイルを選択して取込(推奨)**
   ボタンを押してPDFを選ぶだけです(複数選択可)。確実に動く方式です。
2. **貼り付けたPDFを取り込む(=④の方式)**
   「PDF貼付」シートにPDFをコピー&貼り付け(またはドラッグして埋め込み)し、
   ブックを保存してからボタンを押すと、ブック内に埋め込まれたPDFを取り出して
   読み取ります。
   ※ Excelは貼り付けたPDFを「アイコン(オブジェクト)」としてブック内部に保存する
   だけで中身を読む機能がないため、マクロでブック内部からPDFを取り出しています。
   OneDrive上に保存したブックでは使えないなどの制約があります。

PDFの読み取り自体は、**Power Query(Excel 2021 / Microsoft 365)** を第一候補、
**Word変換(Word 2013以降)** を第二候補として自動で試します。
どちらも使えない古い環境では読み取りできません(その場合は後述のPythonスクリプトを利用)。

## ファイル構成

```
excel-tool/
  動揺データ抽出ツール_テンプレート.xlsx … ツール本体(マクロ組込み前)
  vba/
    modMain.bas      … ボタン・取込・再抽出などのメイン処理
    modEngine.bas    … PDF解析(Power Query方式 / Word変換方式)
    modEmbedded.bas  … 貼り付けたPDFの取り出し(④)
sample/
  サンプル出力_大月保技セ_20260604.xlsx … 添付PDF(2026/06/04測定)を変換した実例
scripts/
  pdf_to_excel.py    … Python版の変換スクリプト(パソコンにPythonがある場合)
  build_template.py  … テンプレートを再生成するスクリプト(開発用)
```

## 初回セットアップ(1回だけ)

1. `excel-tool/動揺データ抽出ツール_テンプレート.xlsx` をExcelで開く
2. `Alt + F11` でVBAエディタを開き、メニューの
   **ファイル → ファイルのインポート** で `excel-tool/vba` の
   `modMain.bas`・`modEngine.bas`・`modEmbedded.bas` を3つともインポート
3. VBAエディタを閉じ、**F12(名前を付けて保存)** で
   ファイルの種類を **「Excel マクロ有効ブック (*.xlsm)」** にして保存
4. `Alt + F8` → **初期設定** を実行(PDF貼付シートにボタンが設置されます)

あとは出来上がった .xlsm を職場内で共有すれば、各自がそのまま使えます。
(開いたときに「マクロを有効にする」の許可が必要です)

> **手順3〜4が最も重要です。** `.xlsx` のまま保存するとインポートしたマクロは
> 消えてしまいます。必ずファイルの種類を **「Excel マクロ有効ブック (*.xlsm)」**
> に変えて保存してください。

### 困ったとき

| 症状 | 原因と対処 |
|---|---|
| **Alt+F8 のマクロ一覧が空っぽ** | 手順2のインポートがまだです。配布ファイルは `.xlsx` でマクロを1つも持っていないため一覧は空になります。先に Alt+F11 から3つの `.bas` をインポートしてください |
| 一覧に「初期設定」が出てこない | インポートしたモジュールが別のブックに入っている可能性があります。VBA画面左の一覧で、このブックの名前の下に `modMain` があるか確認してください |
| ボタンを押しても何も起きない | `.xlsx` で保存し直したためマクロが失われています。もう一度インポートし、`.xlsm` で保存してください |
| ファイルを開くと黄色い警告バーが出る | 「コンテンツの有効化」を押してください。押さないとマクロは動きません |
| 「PDFファイルを選択して取込」でエラー | お使いのExcelがPDF読み取りに対応していない可能性があります(Power Query / Word が必要)。下記のPython版をご利用ください |

## 使い方

1. 「PDF貼付」シートの **「PDFファイルを選択して取込」** を押してPDFを選ぶ
   (または、シートにPDFを貼り付けて保存 → **「貼り付けたPDFを取り込む」**)
2. 「全データ」「①基準値超過」「②目標値超過」が自動で埋まります
3. 設定シートの値を変えたときは **「設定変更後の再抽出」** を押す
   (PDFを読み直さずに①②を作り直します)

複数のPDFをまとめて取り込むと、測定日・元ファイル名の列で区別できます。

## Python版(参考)

Pythonが使えるパソコンでは、マクロなしで確実に変換できます:

```bash
pip install pdfplumber openpyxl
python scripts/pdf_to_excel.py 配布された.pdf -o 抽出結果.xlsx
# しきい値を変える場合
python scripts/pdf_to_excel.py 配布された.pdf -o 抽出結果.xlsx --target 0.25 --limit 0.30 --yellow 0.29
```

`sample/` の実例はこのスクリプトで生成したものです
(添付PDFの全509行、①9件はPDFの`*`印と完全一致、②99件)。

## 注意事項

- VBA版(Power Query方式・Word変換方式)は、お使いのExcel環境での動作確認を
  お願いします。様式が異なるPDFでは読み取りできない場合があります。
- `vba/*.bas` は日本語版ExcelのVBAエディタで正しくインポートできるよう
  **Shift-JIS** で保存しています(GitHub上では文字化けして見えますが正常です)。
- PDFがスキャン画像(文字情報なし)の場合は読み取りできません。
