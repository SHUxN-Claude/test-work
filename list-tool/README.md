# 整備基準値超過箇所一覧 自動入力ツール

下り・上りの「動揺データ抽出ツール(.xlsm)」の**①基準値超過**を読み込み、
`2026年度_列車動揺_基準値超過箇所一覧` の当月シートへ自動転記します。

## セットアップ(初回のみ)

1. 一覧のExcelを開き、**F12** →「Excel マクロ有効ブック (\*.xlsm)」で保存し直す
2. **Alt+F11** →「ファイル」→「ファイルのインポート」で `modList.bas` を取り込む
3. **Alt+F8** →「**初期設定**」を実行
   → 各月シートの右側(AG列付近・印刷範囲の外)にボタンが4つ付き、
     「ひな形（コピー元）」シートが作られます

## 毎月の作業

1. 取り込みたい月のシートを開く(例:`202606（9月）`)
2. **「抽出ツールから取込」** → 下り・上りの .xlsm を選ぶ(まとめて選択可)
3. ファイルごとに**検査方法の確認ダイアログ**が出る(Wチェック)
   - ファイル名に「代替検査」「レールナビ」→ 可搬式、なければ 常設式 と判定
   - [はい]そのまま / [いいえ]逆に変更 / [キャンセル]中止
4. 手入力列(G・M・N・P・Q・R・V・W・X・AA)を埋める
5. **「番号・日数を再計算」** を押す
   → 並べ替え・箇所No・現場No・整備実施期限・日数・判定を計算し直し、取込色を消します

## 自動で埋まる列

| 列 | 内容 | 出どころ |
|---|---|---|
| A | 箇所No | 連番(再計算で振り直し) |
| B | 現場 | キロ程が**±20m**以内の行を1現場にまとめ、先頭行に番号 |
| C | 線名 | 中央本線 |
| D | 線別 | 抽出ツールの線別(下線→下 / 上線→上) |
| E/F | 駅名等 | **駅境界**マスタ。構内なら「駅名/構内」、駅間なら前後の駅 |
| H | キロ程 | 抽出ツールのキロ程 × 1000 |
| I | 検査種別 | 列車動揺 |
| J | 検査方法 | ファイル名から判定 → 確認ダイアログ |
| K/L | 上下動/左右動 | 抽出ツールの値 |
| O | 構造物 | **±25m**以内のトンネル/橋りょう/踏切/分岐器/開きょ/レールを「 / 」で連結 |
| S | 検査実施日 | 抽出ツールの測定日 |
| T | 整備期限種別 | 1 |
| U | 整備実施期限 | S + 14日(種別1) / +29日(種別2) |
| Y/Z | 日数/判定 | V(整備実施日)が入っていれば計算。`Y = V - S + 1` |

K1(走行日)・Q1(施工期限)も自動で入ります。
**G(トラムス判定)とAA(確定基準値)は空のまま**です。

### 構造物の表記ルール

- トンネル: マスタの `笹子Ｔ` → **`笹子トンネル`**
- 踏切: 名前に「載線台」「踏切」「通路」が無ければ末尾に**「踏切」**を追加
- 分岐器: **`駅名 + 番号 + 号`**(英字は全角)。例 `四方津12Ａ号`
- 開きょ: 種別「水路」→ **`下水きょ`**
- レール: 伸縮継目位置があれば **`EJ`**、接着絶縁位置があれば **`IJ`**

「ホーム端」「普通継目」などマスタに無いものは空欄です。手で追記してください。

## 既存行がある月に取り込んだ場合

既存行の**下に追記**し、行に色を付けます。

- **うすい水色** … 今回追加した行
- **うすい赤** … 取込前からある行と**同じ位置(±20m)**だった行(重複の可能性)

見比べて不要な行を削除し、「番号・日数を再計算」を押してください。色も消えます。

## 新しい年度・月

**「新しい月のシートを作る」** ボタンで、年度と暦月を入力すると
`202701（4月）` のようなシートをひな形から作り、A1も `2027年度〜` に変わります。
(4月=01 … 3月=12 の通し番号は自動計算)

## 仕様メモ

- **セルに数式は入れません**(すべて値)。他のExcelへコピペしても壊れません
- **セル結合もしません**。行を足し引きしても崩れません
- 書式は既存に合わせています(`HG丸ｺﾞｼｯｸM-PRO`、キロ程 `0"k"000.0"m"`、
  動揺値 `0.00`、日付 `yy/mm/dd`、全列「縮小して全体を表示」)
- 許容距離を変えたいときは `modList.bas` 冒頭の
  `TOL_STRUCT`(構造物・既定25m)と `TOL_SITE`(現場・既定20m)を書き換えます

## 検証結果(6か月分の実績と照合)

- **E/F**: 44件中35件一致。相違9件は**すべて手入力側の誤り**でした
- **O**: ±25mで36/44件が自動判定(±10mでは23件)
- **8月分**でH・K・L・J・B(現場番号)は実績と**完全一致**
